# コマンドまとめ
Linux系の使っていくことが多そうなコマンドのまとめです.

## cp
`cp [コピー元(コピーするファイル)] [コピー先]`  
でコピーを行うことが可能.

## vi
`vi [開きたいファイル]`  
でファイルを開くことができる.  
カーソルの位置に文字を入力する際は`i`を入力する.(<-***INSERT MODE***)  
***INSERT MODE***のときには***back space***が使用できる.  
入力を終了したいときは***Escキー***を入力する.  
カーソル位置の文字を削除するときは`x`を入力する.  
編集を終了し,保存して終了する際は`:wq`を入力する.
